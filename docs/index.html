Northeastern academic calendar subscriptions

Subscribe to the registrar's PDF calendar as .ics feeds. The mirror rebuilds weekly and groups events by audience and category.

To subscribe in Google Calendar, choose Other calendars → + → From URL and paste a feed link. In Apple Calendar, choose File → New Calendar Subscription. Use the link address for a subscription. Opening a downloaded file imports a snapshot.

current-* feeds track the newest published academic year, currently 2026-2027. A future year's publication switches these feeds before that year begins. Use a fixed-year archive link to keep following a particular year.

Boston undergraduate bundles

Each bundle combines the categories listed. Bundles overlap, so subscribing to several can show duplicate events.

On small screens, scroll tables sideways to reach the feed links.
